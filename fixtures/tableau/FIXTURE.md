# Tableau fixture notes

Workbooks are delivered as packaged **.twbx** files (project convention). A plain `.twb` is only
written on request (`scripts/build_demo_workbook.py --twb`).

## Release gate (every generated .twbx)

`scripts/build_demo_workbook.py` builds into `generated/.staging/` and copies the file to
`generated/` only if all checks pass:

1. **Static check** (`demo/workbook/validate.py`): Tableau's content-model rules for element
   order, learned from Tableau's own errors and from Tableau-authored files.
2. **Live load in Tableau Desktop** (`scripts/tableau_load_check.ps1`), run twice:
   a. the release file as-is;
   b. a check-only copy that opens on a dashboard of all six sheets, so every sheet's queries run.

   A run fails on any Tableau error dialog (full text captured via "Copy Error Message", with the
   clipboard restored afterwards) or any query error in that Tableau process's log. Only the Tableau
   process started by the check is closed.
3. Negative control (2026-10-30): a deliberately broken copy (relationship on a missing field)
   was correctly reported as FAIL, with Tableau's exact message.

What the gate does **not** prove: that the numbers shown match guide section 8. Tableau loads and
queries every sheet without error, but values are not read back.
