Decision (2026-10-30, at the project owner's request): the workbook was generated by script rather
than built by hand in Tableau. Consequence: the generated XML is written by the same team that
writes the parser, so on its own it cannot prove the parser handles real Tableau output. The
Tableau-saved copy closes most of that gap, because Tableau rewrites the whole file in its own
format on save. Phase 2 parses **both**, and treats the Tableau-saved copy as the reference once
it exists. Until then, parser results on the generated file are labelled "generated fixture only".

## How to produce the Tableau-saved copy (about 5 minutes)

1. Build the data if needed: `.\.venv\Scripts\python.exe scripts\build_demo.py --scenarios S0`
2. Open `fixtures\tableau\generated\sales_performance_legacy.twb` in Tableau Desktop.
   (It points at `D:\BIAssurance\demo\data\seed_42\legacy_csv\`. If Tableau asks for the file
   location, browse to that folder.)
3. Open each sheet once. Compare `KPI Summary`, `Revenue by Region` and `Customer Cohorts` with
   the reference values in `docs/demo-workbook-build-guide.md` section 8.
4. **File → Save As** → `fixtures\tableau\sales_performance_legacy.twb`; then save as packaged
   workbook → `fixtures\tableau\sales_performance_legacy.twbx`.
